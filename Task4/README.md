# Task4：海龟交易策略与回测

## 任务目标

本任务在 Task3 已保存的10只A股前复权日线基础上，实现一个可解释、可回测、可调参的海龟趋势跟踪策略：

1. 解释海龟策略、高低点通道、ATR、风险定仓与止损规则；
2. 使用 Python 计算通道、Wilder ATR、买卖信号和模拟交易；
3. 绘制股价、通道、ATR、止损、交易点、净值和回撤；
4. 计算累计回报、年化收益/波动、MDD、夏普、胜率、交易次数和基准收益；
5. 比较不同股票、行业、通道周期和ATR止损参数的样本外表现；
6. 输出 CSV、PNG、Markdown、教学 Notebook、统一风格静态网页和 Word 报告。

## 默认策略规则

- **入场通道**：收盘价首次突破截至前一交易日的20日最高价；下一交易日开盘买入。
- **离场通道**：收盘价跌破截至前一交易日的10日最低价；下一交易日开盘卖出。
- **ATR**：20日 Wilder ATR；真实波幅取 `max(high-low, |high-prev_close|, |low-prev_close|)`。
- **止损**：入场价减去 `2 × 入场信号日ATR`；若跳空低开越过止损价，按开盘价成交。
- **风险定仓**：每笔计划损失不超过当时账户权益的1%，资金使用不超过100%。
- **交易约束**：只做多、不加杠杆、不加仓，允许教学用小数股。
- **成本**：买卖单边综合交易成本均按0.1%估计。
- **避免前视偏差**：高低点通道统一使用 `shift(1)`；普通通道信号次日执行。

## 数据与样本

行情直接读取 `Task3/data/*_daily_qfq.csv`，共10只跨行业股票，覆盖约2019-01至2026-07。关键 OHLC 日期字段无缺失、无重复交易日；非核心辅助字段的缺失不会进入本策略计算。

- 样本内：2019-01至2023-12；
- 样本外：2024-01至2026-07；
- 参数组合：10/5日、20/10日、40/20日和55/20日通道，并比较1.5、2、3倍ATR止损。

## 当前样本外结论

默认 `E20/X10/ATR20/S2` 在10只股票中有7只取得正累计回报；中位累计回报约0.61%，中位夏普约0.08，中位最大回撤约-5.83%。长电科技、北方华创、宁德时代和徐工机械表现相对较好，食品饮料样本表现偏弱。

跨股票比较中，`E40/X20/ATR20/S2` 的样本外中位夏普最高，约0.30；但与短周期 `E10/X5/ATR14/S1.5` 非常接近，说明参数排名并不稳定，不能只根据一个样本挑选“最优”参数。

## 研究限制

- 股票池为人工选择的当前代表性股票，存在幸存者偏差，每个行业仅2只股票；
- 未模拟100股整手、涨跌停无法成交、停牌、滑点、容量和税费结构变化；
- 前复权价格、允许小数股、零无风险利率和固定交易成本均为教学假设；
- 结果用于理解策略结构和参数敏感性，不构成投资建议。
