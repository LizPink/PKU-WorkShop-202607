# Task2 金融数据技术指标分析

## 任务思路
1. 读取本地 CSV，统一日期和数值字段。
2. 先做缺失值与描述性统计，确认数据可用。
3. 基于收盘价与 OHLC 数据计算 RSI、MACD、布林带和 ATR。
4. 输出指标 CSV、图表 PNG、Markdown 报告，并由 `build_site.py` 生成网页。
