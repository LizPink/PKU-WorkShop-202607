## 1. 项目目标

围绕“AI 交易引擎：机器学习算法与场景应用”完成一份可复现、可解释、符合提交格式的课程作业。最终成果不仅回答三项题目，还应形成从数据加载、数据划分、模型训练、概率预测、指标评价到图表解读的完整证据链。除正式提交的 PDF 外，还将延续前几个任务的结构，生成一个本地静态 HTML 成果页，用于集中浏览实验流程、核心指标、混淆矩阵、ROC 曲线和复现说明。

为使“正类”含义更直观，实验中将把标签重新编码为：恶性肿瘤 = 1，良性肿瘤 = 0。报告会明确说明这与 scikit-learn 原始编码（恶性 = 0、良性 = 1）的差异，避免混淆矩阵、召回率和 ROC/AUC 的方向被误读。

## 3. 理论部分写作计划

### 3.1 分类算法

1. **逻辑回归**
   - 用线性组合和 Sigmoid 函数估计样本属于正类的概率；
   - 以 0.5 为默认分类阈值，但说明阈值可根据误判成本调整；
   - 优点是速度快、可解释性较强、能输出概率；局限是默认决策边界为线性，且对特征尺度较敏感；
   - 对应量化场景：预测下一期上涨/下跌、违约/不违约或交易信号是否有效。

2. **决策树**
   - 通过基尼不纯度或信息增益递归划分特征空间；
   - 优点是规则直观、可描述非线性关系且不要求特征标准化；局限是容易过拟合、对样本扰动较敏感；
   - 对应量化场景：根据估值、盈利能力、动量和波动率等指标形成可读的分类规则。

3. **随机森林**
   - 对多个 bootstrap 样本训练决策树，并在节点划分时随机抽取部分特征，最后投票或平均概率；
   - 优点是通常比单棵树更稳定、能拟合非线性和交互效应；局限是解释性下降、计算量增加；
   - 对应量化场景：融合多类财务和市场特征预测收益方向或风险事件。

理论部分会强调：乳腺癌实验是分类算法的标准教学验证，迁移到量化交易时，应变量可替换为“未来收益是否为正”或“是否跑赢基准”，但必须避免未来数据泄漏，并采用按时间先后划分或滚动回测，而不能直接随机打乱时间序列。

### 3.2 评价指标

报告将统一以“恶性 = 正类（1）”解释以下概念：

- **混淆矩阵**：由真正例 TP、假正例 FP、真负例 TN、假负例 FN 组成；说明矩阵行列含义，防止不同软件显示方向不同造成误读。
- **准确率**：`(TP + TN) / (TP + TN + FP + FN)`，类别不均衡时可能产生误导。
- **精确率**：`TP / (TP + FP)`，关注被预测为正类的样本有多少确为正类。
- **召回率/敏感度/真正率**：`TP / (TP + FN)`，关注真实正类被识别出的比例。
- **特异度**：`TN / (TN + FP)`，衡量真实负类被正确识别的比例。
- **F1 值**：精确率与召回率的调和平均。
- **ROC 曲线**：改变分类阈值，以假正率 `FPR = FP / (FP + TN)` 为横轴、真正率 `TPR = TP / (TP + FN)` 为纵轴得到的曲线。
- **AUC**：ROC 曲线下面积，可理解为随机抽取一个正类和一个负类时，模型把正类预测分数排在负类之上的概率；0.5 附近接近随机排序，越接近 1 区分能力越强。

同时说明：AUC 衡量排序能力，不直接决定某个固定阈值下的交易收益、诊断成本或分类正确率。因此结论需结合混淆矩阵、业务代价和阈值共同判断。

## 4. Python 实验设计

### 4.1 环境与依赖

计划使用 Python 3.11+，核心依赖为：

- `scikit-learn`：数据集、数据划分、模型、评价指标；
- `pandas`、`numpy`：数据整理和结果表；
- `matplotlib`、`seaborn`：混淆矩阵和 ROC 图；
- `python-docx`：生成符合格式的 DOCX；
- PDF 转换及渲染工具：生成 PDF 并逐页检查版式。

实施时会把缺少的依赖加入根目录项目配置和锁文件，确保其他机器可按同一环境复现。

### 4.2 数据处理

1. 调用 `sklearn.datasets.load_breast_cancer(as_frame=True)`；
2. 检查样本数、特征数、缺失值、重复记录和原始类别分布；
3. 将标签映射为恶性 = 1、良性 = 0；
4. 使用 `train_test_split` 按 80%/20% 划分训练集与测试集；
5. 设置 `stratify=y` 保持两部分的类别比例接近，并固定 `random_state=42`；
6. 所有预处理步骤仅在训练集拟合，测试集只用于最终评价，防止数据泄漏。

### 4.3 模型方案

为便于比较，训练以下三个模型：

| 模型 | 预处理 | 初始方案 |
| --- | --- | --- |
| 逻辑回归 | `StandardScaler` + `LogisticRegression` 管道 | 提高收敛上限，固定随机种子 |
| 决策树 | 无需标准化 | 控制 `max_depth`、叶节点最小样本数，抑制过拟合 |
| 随机森林 | 无需标准化 | 固定树数量和随机种子，可使用类别权重 |

如需选择树深等超参数，将只在训练集内使用分层交叉验证完成；测试集不得参与调参。报告会列出最终参数，而不是隐藏默认值。

### 4.4 评价方法

每个模型在测试集上输出：

- 预测类别和正类预测概率；
- 混淆矩阵；
- Accuracy、Precision、Recall、Specificity、F1；
- ROC-AUC；
- ROC 曲线所需的 FPR、TPR 和阈值序列。

模型比较以测试集 ROC-AUC 为主要排序指标，同时结合召回率和混淆矩阵讨论误判。对于医学样例，漏判恶性（FN）通常代价更高；迁移到交易时，FP 与 FN 的代价则分别对应无效交易和错失机会，需要结合手续费、滑点与风险偏好重新定义。

### 4.5 HTML 成果页

实验完成后生成 `web/index.html`，作为项目的本地浏览入口。页面采用静态 HTML、CSS 和少量 JavaScript，不依赖后端服务，双击即可查看。计划包含：

- 任务目标、数据来源、正类定义和训练/测试集划分说明；
- 三种算法的简明原理卡片；
- Accuracy、Precision、Recall、Specificity、F1 和 AUC 对比表；
- 三个混淆矩阵和一张综合 ROC 曲线；
- 对关键结果的文字解读及量化交易迁移提示；
- Python 运行方式、输出文件和最终 PDF 的导航链接。

HTML 与 PDF 共用同一批脚本生成的指标和图片，避免两套结果口径不一致。HTML 是辅助展示与检查材料，不替代任务要求的最终 PDF 提交件。

## 11. 风险与控制

- **标签方向风险**：显式重编码并在数据、图表和指标函数中统一指定正类为 1。
- **数据泄漏风险**：标准化放入模型管道，仅在训练集拟合；测试集不参与调参。
- **类别不平衡风险**：使用分层划分，并同时报告 AUC、召回率、特异度和混淆矩阵。
- **过拟合风险**：限制决策树复杂度，随机森林固定合理参数；比较训练与测试表现或在训练集内做交叉验证。
- **中文字体风险**：生成图表和文档前检查本机宋体可用性，PDF 导出后检查字体和乱码。
- **格式风险**：通过文档样式统一控制字体、字号、行距、段距和对齐，并对最终 PDF 做逐页视觉检查。
- **命名风险**：姓名未提供前只生成占位版本；最终提交前再按确认姓名复制为正式文件名。
